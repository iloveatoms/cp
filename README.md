## Getting Started

Deploy the Server:

> 1. Build static files
```bash
/cp/webapp/complaint-portal $ npm run build
```
> 2. Start Web server
```bash
/cp/webapp/complaint-portal $ npm run dev
```
> with that running..., in another terminal
> 3. Start Database Server | RUN
```bash
/cp/server $ python server.py
```

Open [http://localhost:5000](http://localhost:5000) 😀
Available at all interfaces

Admin Panel:
> Only @ [http://localhost:9999](http://localhost:9999)
